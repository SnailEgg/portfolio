Video Game Development

One Small Breath

2025

A Next.js app made for the final project of a web apps course, One Small Breath is an experimental game where you must talk to an AI chatbot to learn how to escape the room you wake up in.

Lagum

2025

In Lagum you can slow the framerate for everything except yourself. Made with a friend in three days for the Patch Notes v1.0 game jam.

Slidle

2025

My final project for a college web scripting course, Slidle is a block-sliding puzzle game written with vanilla JS and JQuery UI. If I expand this game in the future, I will rewrite it with more modern tools, but for now, it serves as a demo.

Treasure of Torment

2019

My final project in a high school game programming course, I programmed Treasure of Torment in Blitz Basic. It features platformer physics, enemy AI, and an event-timing system, all built from the ground up.

Due to use of assets from Shovel Knight by Yacht Club Games, Treasure of Torment can not be published.

DON'T Breakout

2019

The first game I wrote in Blitz Basic for a high school game programming course, DON'T Breakout implements procedural levels and high-score saving.

Aether

2018

My final project for a GameMaker-based game development course in high school, Aether experiments with collectibles, unlockable abilities, and multiple endings.
